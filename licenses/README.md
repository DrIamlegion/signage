# Third-party licenses

These files are distributed with Signage and Signage Studio so the notices for
the bundled DeckCraft components travel with the binaries.

- `DeckCraft-NOTICE.txt` and `DeckCraft-ATTRIBUTION.md` come from
  `deckcraft/deckcraft-main` and must be kept with distributions that include
  DeckCraft.
- `DeckCraft-LICENSE-APACHE.txt` and `DeckCraft-LICENSE-MIT.txt` are the two
  upstream DeckCraft license options.
- `DeckCraft-font-licenses.txt` contains the full OFL texts for the fonts
  embedded in the native DeckCraft build.
- `pdf-writer-LICENSE-ICC.txt` covers the Compact ICC Profiles used by the PDF
  writer.
- `ArtCraft-brand-LICENSE.txt` contains the terms for the ArtCraft brand assets.
  The Signage Studio installer does not install the ArtCraft wordmark or logo
  files.

The root `LICENSE` is the Apache License, Version 2.0 for Signage's own code.
The root `NOTICE` and `THIRD-PARTY-NOTICES.md` explain the combined
distribution.
